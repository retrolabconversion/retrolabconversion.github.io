Your first publication

  1. Create your free GitHub account.Enable two-factor authentication to protect your publications.
    Create a GitHub account
  2. Create a public repository.A repository named rlc-releases can hold your published game builds. You do not need to upload your game source code.
  3. Connect the catalogue once.Share your repository link with the site maintainer. The website needs its public owner and repository name; no account password or upload token.
  4. Prepare and publish your release.Use the form, copy the release notes, then attach your ROM on GitHub's release page and publish. Keep the generated project marker so the site matches your file to the right game.

Files stay on your computer until you upload them on GitHub. Only authorised GitHub contributors can publish. Read GitHub's release guide.
